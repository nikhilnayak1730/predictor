# predictor
# TrajectoryAI Agent Platform

A React-based web application that analyzes talent profiles and predicts career trajectories using Large Language Models. 

## Tech Stack
* **React 18**
* **Vite**
* **Anthropic / OpenAI API**

## How to Run Locally

1. Install Node.js if you haven't already.
2. Clone this repository.
3. Run `npm install` in your terminal to install dependencies.
4. Run `npm run dev` to start the local development server.
5. Open `http://localhost:5173` in your browser.

## Deployment
This project is built with Vite and can be easily deployed to Vercel, Netlify, or GitHub Pages. 
To build for production, run `npm run build`.
